**🐝 BEES

**Misiones pequeñas. Decisiones grandes.**

BEES ayuda a elegir entre varias opciones cuando decidir se vuelve complicado. El jugador escribe las opciones y el juego propone una forma de sortearlas.

## 🎯 Tu misión

1. Instala las dependencias: `npm install`
2. Inicia el juego: `npm run dev`
3. Abre la dirección que muestre Vite.
4. Escribe entre 2 y 10 opciones.
5. Inicia el juego y descubre el escenario seleccionado.

## 🛠️ Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Phaser
- Zustand

## 🧭 Estructura útil

- `src/App.tsx`: flujo principal de la pantalla.
- `src/components/`: componentes de interfaz.
- `src/services/`: lógica para seleccionar escenarios.
- `src/types/games.ts`: tipos compartidos del juego.

## ✅ Comandos

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## 🤝 Cómo colaborar

Usa una rama por tarea, escribe cambios pequeños y ejecuta `npm run build` antes de subirlos. Los nombres claros valen más que los comentarios largos.
